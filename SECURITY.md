# 🛡️ Security Policy

CampusLink takes the security and integrity of academic records, research intellectual property, and user privacy seriously.

---

## 🔒 Supported Versions

We provide active security patches and updates for the following releases:

| Version | Supported |
| :--- | :---: |
| 1.0.x (Current Main) | ✅ Active |
| < 1.0.0 | ❌ End of Life |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or potential threat within CampusLink:

1. **Do NOT publicly disclose the issue via GitHub issues, pull requests, or public forums.**
2. Send an email to the security response team at **`security@campuslink.ac.in`** (or create a private GitHub Advisory).
3. Include the following details in your report:
   - Component / Route affected (e.g. JWT session, CORS policy, RBAC middleware).
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - Assessment of potential impact (e.g. privilege escalation, unauthenticated data access).

---

## ⏱️ Response & Disclosure Timeline

- **Initial Triage:** Within **24 hours** of report receipt.
- **Fix Verification & Patching:** Within **72 hours** for high or critical severity vulnerabilities.
- **Public Disclosure:** Following mutual agreement and deployment of the security patch.
